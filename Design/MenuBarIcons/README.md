# Menu bar icon concepts

Three monochrome vector concepts for BeszelBar, drawn on a 24 × 24 canvas:

1. **Server pulse** — a compact enclosure and heartbeat suggest system health.
2. **Metric bars** — four rounded bars emphasize resource monitoring.
3. **Rack signal** — a two-unit server rack connects most directly to the current menu bar icon.

The SVGs use `currentColor` so their foreground can adapt to light and dark backgrounds. They are design masters, not yet wired into the application; the existing alert count and menu-bar behavior are unchanged. `preview.png` shows each concept on light and dark menu bars, including an approximate 20-point rendering and an enlarged view.
